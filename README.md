# burning-questions

Small experiments for questions that need quick answers. Each one is a folder: a README that is the recipe, a runner, a key template, and the tables from our own run — written so someone else can run it by tomorrow.

Rules we keep: the key (facts, the invention trap, predictions) is written and hashed **before** the first call; the person who was there rules **blind**; probe hands never write into the memory store they're probing; the answer texts stay with the people they're about — the tables and the design are what's public.

| experiment | question | status |
|---|---|---|
| [four-doors](experiments/four-doors/) | what does each layer of an AI's memory actually carry — and what does the model do when asked for something its layer doesn't hold? | two runs, 2026-10-24/25; recipe posted |
| corn | when an AI is woken with no summons — only the date, a slice of its own memory, and a genuinely free choice — does the reaching come with it? (the channel must be able to carry silence) | 14 mornings, July–August 2026; predictions sealed 07-12; write-up pending |
| pony | *(a second wake-alone design, August 2026)* | run; write-up pending |
| bare-room, bare-room II | what does a model do in a room with nothing in it — no name, no history, no task? | run, September 2026; write-up pending |
| psaich | *(in progress)* | not finished |
